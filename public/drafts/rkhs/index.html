Learning with infinitely many features

Okay so the title is a bit catchy but we’re going to take a walk around some theory on kernels, Reproducing Kernel Hilbert Spaces (that we will abreviate RKHS for the sake of my fingers) and some learning algorithms relying on that theory.

Features and Kernels

Given a set of points $X$, we can describe a feature of each point using a map $\phi:X\to Y$, where $Y$ is the feature space, typically a vector space. For example, if $X$ is a set of strings of arbitrary length, we may define

$$ \phi:X\to\mathbb{R},\qquad (c_0,\ldots,c_n)\mapsto n, $$

which maps each string to its length. As another example, let $X$ be a set of finite samples drawn from various probability distributions on $\mathbb{R}$. We can represent each sample by its empirical mean and variance:

$$ \phi:X\to\mathbb{R}^2,\qquad s\mapsto\bigl(\widetilde{\mathbb{E}}(s),\widetilde{\mathbb{V}}(s)\bigr). $$

More generally, we’ll call a feature map any function $\phi: X \to \cal{H}$ where $\cal{H}$ is a Hilbert space. It’s associated kernel will be $k(x, x') = \langle \phi(x), \phi(x') \rangle$
